## 常见代号

| 名称 | 普通中文解释 |
|---|---|
| C1-A | 新“初步参考推荐”的计算模块 |
| C1-B | 把计算结果接到用户可见页面 |
| C2 | 用户主动保存单个老人的评估，并能再次/跨设备读取 |
| Contract / Frozen | 已明确的一版业务规则；修改语义时要说明版本影响，不等于每次改页面都需审批 |
| Demo / Mock | 演示或测试数据，不代表真实预约、真实机构能力或正式保存 |
| PASS / 未验证 | 只说明具体检查结果，不能替代用户能否实际使用的解释 |

历史报告、截图和日志按需读取。新增长期总结时，同时补阶段索引一行即可，不增加多份报告或审批。
