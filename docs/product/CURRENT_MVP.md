# 当前 MVP 范围与页面导航

更新：2026-10-27。**V1.2 是产品基线；V1.3 是后继目标。** 本文件说明用户如何走完流程，以及哪些功能已经有界面、哪些只在演示中可用。功能状态与产品规则见 [当前产品说明](CURRENT_PRD.md)。

## 1. 用户应能走的三条路线

### 想先了解机构

首页 → 查找养老机构 → 按名称/区域/性质筛选 → 机构详情 → 查看合法资料、通用指南或咨询入口。普通目录方便浏览，不宣称已按该老人需求匹配。

### 想先整理家人的照护需求

首页 → 评估说明 → 六步问卷 → 老人需求画像 → 评估与机构选择 → 机构详情。问卷为 32 项、26 必填、6 选填；不确定可保留，画像可返回相应步骤修改。

当前结果页已接入 C1-B 独立初步参考卡：保留本次答案与旧结果，写清参考依据与关键能力待核实；已有合法旧候选时不混入参考补数，无依据时可转普通目录。定向自动化与双构建通过，手机验收待完成。

### 想继续咨询、看院和回顾

机构详情 → 顾问/看院安排 → 我的预约 → 已完成看院的评价；我的 → 老人档案/我的评估 → 当次记录。**图册展示的是 Demo 模拟闭环。** 正式预约、顾问服务和跨设备历史需要真实服务能力，目前不能由这些画面判定完成。

## 3. 每条路线都要写清三种结果

| 用户操作 | 正常完成 | 暂时没有内容/不具备条件 | 操作失败 |
|---|---|---|---|
| 填问卷、看画像 | 保留答案并显示需求摘要 | 未填必填题定位到题目；未知仍保留未知 | 保留合法输入，说明恢复办法 |
| 看个性化结果 | 显示合法候选、依据和差异 | 无候选说明原因，允许浏览普通目录 | 资料或服务故障不能写成“没有合适机构” |
| 查机构详情 | 显示所选机构版本与资料状态 | 缺参数/无资料分别提示；未核验不写成不支持 | 返回目录或重试 |
| 使用 FAQ 或顾问 | FAQ 显示已批准答案；Demo 顾问明确为本地示例 | 无答案/无真实顾问服务如实说明 | 保留问题，不显示已联系真人 |
| 提交预约 | 有可信受理回执才显示申请已提交 | 服务未开放或无有效回执时说明原因 | 保留填写内容，不显示预约已确认 |
| 查看历史 | 打开当次只读快照 | 无记录、未开放、未授权、旧版本不支持分别说明 | 加载失败不伪装为空列表 |
| 填写评价 | 由合法完成看院进入，总体体验→现场观察→最后确认 | 没有有效看院记录时提示入口问题；选填留空 | 保存失败保留草稿，不改写机构事实 |
| 看 VR/地图 | 合法机构资源或明确标示的演示画面 | 不可用说明状态；合成全景与城市底图保持演示标识 | 重试/返回，不补造院址或实景 |

页面依赖上下文时，应从相应用户入口进入：详情需要机构 ID 与版本，老人详情需要老人 ID，历史快照需要评估 ID，评价需要已完成看院 ID，预约结果需要有效一次性回执。直接打开路由的空态是必要页面状态，不代表应该去掉校验。

## 4. 当前接入与后续目标

### C1-B：初步参考已接入页面

完成后，用户如实填完问卷，可以看到旧结果或独立初步参考；每张参考卡写清可信依据、未知能力和下一步核实方式。已知关键冲突不靠地区/费用抵消；最多三家，无依据不凑数。零候选和加载失败有不同说明。

2026-10-27 已完成页面接线及定向自动化：覆盖旧单卡优先、1–3 张参考、旧 blocked 状态保留、空态/错误区分、公开详情与刷新保护；风险与全部澄清不截断。DevTools 使用隔离合成夹具核对 320／375／430px、150% 字号的首屏、首卡风险与详情按钮，以及公开详情跳转，证据在主根 output/c1-b；手机字体、触控和完整长列表滚动尚需 Owner 验收。旧图册第 30 页仍只是此前演示候选证据。

### C2：一位老人的正式保存和读取

完成后的用户路径：完成评估 → 预览 → 主动保存 → 必要登录和老人关联 → 可信成功结果 → 我的评估 → 当次只读快照。无候选也可保存；修改问卷后旧记录不变；重复点击和网络恢复不生成重复记录。

目前正式后端方案仍待落地；不能把 Demo 内存记录改个标题当正式历史。首期只做一位老人，多老人切换和更多记录管理另行安排。

### 本阶段不顺带增加的范围

公开评分、自动医疗判断、AI 重排/报价、在线支付、复杂 CRM、全国机构平台不加入这次文档整理。三个阅读页、城市地图和演示全景按现有边界保留，不为凑齐旧页面数删除，也不复制一个新小程序承载它们。

## 5. 完成一阶段怎样说明

一份短总结就够，写清：**这次让用户多完成了什么、改了哪些页面、实际怎么验证、哪些仍未做、下一步是什么。** 标明 Demo/正式模式与证据日期；截图只证明看到的状态，旧阶段测试不能记成本轮重跑。
