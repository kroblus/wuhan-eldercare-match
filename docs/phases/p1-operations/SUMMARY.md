# 联系、带看与机构报告：本机合成闭环

2026-10-28（北京时间）。P1-2 是联系与排期，P1-3 是最小机构汇总和 Excel。当前可在本机演示完整业务链，真实服务保持关闭；不是正式上线或人工验收。沿用 P1 R1 和 V5，不涉及收费或 C1/C2 冻结语义。

## 做成了什么

- 同一申请可以多次联系，记录实际结果、内部备注、下次联系时间与下一动作；同一操作重试不重复。拒绝联系结束待办，并取消尚未完成的行程；入住反馈必须注明来源与关联机构。
- 同一需求有多场独立看院：待确认、双方确认、改期、逐场取消、到访、未到访分别保留。意向和草稿不占用时段；时间经过不会自动变成已到访。已有到访不能用取消整个需求抹除历史。
- 排期在保存事务内获取按数据环境隔离的专用锁，再检查半开区间、前后缓冲、负责人、本人和手工不可用时段。空日程上的并发确认也只能成功一个；改期失败保留旧安排，版本冲突需刷新。机构只在管理员明确配置容量时限流，日程查询展示实际已配置值。
- P1 没有老人关联，使用可信认证账号作为保守冲突键，覆盖该账号的全部需求；不会从手机号推断同一老人，不支持跨账号家庭共享。负责人用稳定的手工标识，同一人须保持一致；缓冲是可调整设置，不是交通测算。
- 小程序同步本人状态与各场机构、时间、集合说明，全部显示北京时间；未确认时间不公开，后台备注、负责人身份不返回本人接口。保留原申请幂等、失败恢复、双击与卸载后的响应保护。
- 后台分页可浏览超过100条。报告独立查询完整范围，用同一 MySQL 一致性读生成持久化聚合快照，预览与导出读同一批次。平台去重需求、机构关联需求、期间活动、同批需求转化、场次与有来源反馈分开。
- 标准 XLSX 含“报告总览、需求画像汇总、机构服务成果、统计口径”，有橙色表头、图表、数字单位、比率公式、冻结、列宽、横向 A4 打印与页脚。默认没有姓名、电话、账号、集合说明、健康明细、备注、隐藏页或外部链接；导出需后台身份和 CSRF，保留最小导出记录。
- 区域、预算、年龄、日常协助没有结构化采集，保持“未采集”。服务场景任一非零类别少于5条时整维抑制，避免差额反推；不做敏感交叉表。合成报告显著标记，不冒充真实获客；无访问埋点便不展示 UV/PV。

## 朋友坐在本机怎样试

1. 打开 [本机工作台](http://127.0.0.1:18341/p1-admin/)。这是 loopback 地址，朋友不能在远程或手机直接打开。管理员临时账号、密码只在本机 `output/p1-operations/runtime.private.json`；由 Owner 本机查看填写，不发送文件或凭据。
2. 登录后选一条“合成闭环演示”或“待安排”需求，先记录一次未接通、下次联系和动作，再记录已接通。查看下方两次事件均保留。请始终使用合成称呼与测试号码，不联系任何真实人。
3. 新增一场带看，填写机构、同一负责人、北京时间起止、集合说明和缓冲。先仅保存待确认，查看状态；取得合成场景中的双方确认后选择确认。再建一场重叠行程，观察冲突被拒；换无冲突时间后保存。
4. 对已确认场次改期；取消另一场，确认其他安排仍保留。模拟到访时使用已发生的历史合成时段，再明确记录实际时间。未来行程不能提前记到访。日程变更后重新查询，获取最新状态。
5. 在“机构服务报告”选日期、机构和合成来源，生成预览，再下载本批次 Excel；修改筛选后需重新生成。对照批次、需求数、场次和同批分母。150%阅读字号可直接选择；窄屏宽表支持左右滚动。
6. 本机小程序逻辑与真实 HTTP/数据库的整链演示，可在主根运行下列命令；默认会再造155条合成请求，已有夹具时加 `--reuse-report-fixture` 复用，避免重复扩充。脚本执行实际页面提交/刷新 handler 与客户端，身份由 test-classpath-only 服务提供，不代表真实微信登录或 GUI 联网提交。

```powershell
node scripts/check-p1-operations-http.mjs --synthetic-runtime output/p1-operations/runtime.private.json --with-reports --reuse-report-fixture
```

小程序从 `dist/production` 的首页进入“咨询与带看意向”。真实服务默认不可提交；本轮视觉验证使用同批数据库 HTTP 响应注入页面夹具。Demo 保持零 P1 真实网络；没有短信或微信通知，刷新可见不等于消息送达。

需重启时，由 Owner 使用既有专用隔离 MySQL 和 Java21+；启动器读取本机私有配置，不打印凭据：

```powershell
# JAVA_HOME 指向本机 Java21+，并保证 Maven 使用该版本；不要把私有配置上传。
./server/tools/start-p1-synthetic.ps1 -DatabaseSettings output/p1-1/mysql.private.json -JavaExecutable "$env:JAVA_HOME/bin/java.exe" -OutputDirectory output/p1-operations
```

启动器不会替换已占用端口或别的项目进程。私有 MySQL 必须仍可用，禁止使用3306。登录会话正常到期后重新登录，不延长安全策略。
