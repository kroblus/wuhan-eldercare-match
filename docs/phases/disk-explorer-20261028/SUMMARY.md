# 2026-10-28：本机项目空间分析网页

已为主项目生成类似 WizTree 的目录占用网页：`output/disk-explorer/index.html`。页面自带数据、样式与脚本，无外部资源或网络请求；扫描快照和截图留在本机，不提交或上传。

现在可以从目录树、快捷入口、面包屑及矩形图下钻目录；在当前目录及子目录搜索名称/路径，按大小、名称、文件数排序，分页查看；按文件类型筛选，查看选中文件大小、时间与完整路径，复制路径，导出当前全部筛选结果 CSV。网页只读，不提供删除操作。

## 更新与大小口径

在主根运行 `python tools/disk-explorer/scan.py`，然后重新打开或刷新生成网页。刷新浏览器只更新页面，不重新读取磁盘；“重新扫描”按钮提供明确的本机命令。源码、用法与定向检查在 [tools/disk-explorer](../../../tools/disk-explorer/README.md)。

扫描只读取名称、逻辑字节大小及修改时间，包含隐藏文件、Git、依赖、构建、历史证据和归档，排除报告自己的整个目录。不跟随符号链接/junction 等重解析点；无法读取和跳过项明确列出。逻辑大小不等于 NTFS 分配空间，硬链接按路径分别计数。

本轮快照约 5.10 GiB、53,503 个文件、7,453 个文件夹；8 个链接/重解析点未跟随，不伪报完整物理磁盘占用。计数随后续工作变化，以页面扫描时间为准。HTML 含本机路径和元数据，默认仅留本机。

## 本轮验证与界限

- Python 4 项定向检查通过：大小/文件夹数汇总与报告自身排除、链接不跟随、恶意字符串不能结束内嵌 JSON 脚本、非目录输入拒绝；JS 语法检查通过。
- 本机 `127.0.0.1` HTTP 预览返回 200。真实浏览器核对目录/矩形图下钻、上级返回、无结果与 ZIP 搜索、大小排序、选中详情、类型筛选/清除、扫描命令及跳过项说明；控制台未见 warning/error。
- 窄屏无横向溢出；已根据实测将详情标签列缩窄，修复大字节数末位单独换行。
- IAB 浏览器禁止打开 `file://` URL，未绕过此限制，因此离线双击运行没有本轮浏览器实测证据。生成文件为自包含普通脚本 HTML，不依赖 HTTP 数据请求，可由用户本机浏览器打开。未部署到外网，未改小程序业务流程。
